# Мапа ризиків

Статична мапа для людини, яка живе в Кракові. Вона показує туристичні рівні ризику країн, окремі перевірені записи й заголовки з відкритих стрічок. Увесь інтерфейс українською.

Мапа не передбачає конкретних атак і не замінює повідомлення поліції, міста чи MSWiA.

Після увімкнення GitHub Pages сайт відкривається за адресою <https://d413422.github.io/danger-map/>.

## Локально

Потрібен лише статичний сервер. З кореня репозиторію:

```bash
python3 -m http.server 4173
```

Далі відкрийте <http://127.0.0.1:4173/>. Файл `index.html` не варто відкривати просто з диска: браузер не віддасть JSON.

Перевірка даних і розбору стрічок:

```bash
npm install
npm test
```

`npm install` потрібен лише щоб перезібрати межі країн (`topojson-client`) і щоб спрацював `npm test`. Сам сайт залежностей не збирає.

## Файли даних

Редагуйте JSON у `data/` і оновлюйте сторінку. Нічого не вигадуйте: кожен запис має лишатися прив’язаним до джерела, яке ви справді відкрили.

### `data/meta.json`

Знімок і межі шкали часу.

| Поле | Зміст |
| --- | --- |
| `asOf` | Дата знімка, `YYYY-MM-DD` |
| `zone` | Часовий пояс підписів, зараз `Europe/Warsaw` |
| `from`, `to` | Кінці шкали часу |
| `advisory` | Сторінка туристичних рівнів США |
| `homicide` | Вторинна таблиця коефіцієнтів умисних вбивств |
| `previousPage` | Попередній прототип, якщо він ще доступний |
| `todayImportant` | Ідентифікатори записів для вкладки «Сьогодні важливо» |

### `data/countries.json`

Один об’єкт на код країни, для якої є зібраний рівень. Решта світу на мапі сіра й підписана «немає даних».

| Поле | Зміст |
| --- | --- |
| `code` | ISO 3166-1 alpha-2. Косово в цьому наборі — `XK` |
| `name` | Українська назва |
| `lat`, `lon` | Опорна точка країни, не межа |
| `advisory` | `1`–`4` або `null`, якщо числового рівня немає |
| `notes` | Коротко, звідки взято рівень |
| `homicidePer100k` | Коефіцієнт на 100 тис. або `null` |
| `homicideYear` | Рік коефіцієнта або `null` |

Сторінка сама робить із цього запис `c-КОД` (наприклад `c-PL`). Його не треба дублювати в `records.json`.

### `data/records.json`

Події, календар, режими, місцева статистика й неофіційні сигнали. Країн тут немає.

Обов’язкові поля: `id`, `title`, `date`, `dateKind`, `place`, `lat`, `lon`, `type`, `confidence`, `description`, `sources`, `kind`, `sourceKind`, `links`.

Необов’язкові: `endDate`, `country`, `avoid`.

- `date` і `endDate` — `YYYY-MM-DD`.
- `type`: `терор`, `війни`, `кримінал`, `кібер/банки`, `протести`, `політика`. На екрані `терор` підписано «тероризм».
- `confidence`: `неперевірений сигнал`, `одне джерело`, `підтверджено`.
- `kind`: `подія`, `календар`, `режим`, `локально`, `X` або інша ваша позначка виду.
- `sourceKind`: `офіційне`, `медіа`, або для неофіційного шару одне з `X`, `telegram`, `неофіційне`, `місцеві новини`.
- `sources` — список `https`-посилань.
- `links` у записі можна лишати порожнім. Редакційні зв’язки лежать у `links.json`. Сторінка додає їх до обох записів і сама проводить географічну дугу до країни, якщо заповнено `country`.
- `avoid` — практична порада лише тоді, коли її дає джерело. Не вигадуйте небезпечні вулиці.

`lat`/`lon` — опорна точка. Якщо це не місце самої події, так і напишіть у `place` або `description`.

Неофіційний сигнал завжди показується як «неперевірений сигнал», навіть якщо в полі `confidence` стоїть інше. Приклад порожнього шаблону, не як реальний запис:

```json
{
  "id": "x-приклад-не-публікувати",
  "title": "Замініть на справжній заголовок",
  "date": "2026-11-08",
  "dateKind": "час допису",
  "place": "Краків",
  "lat": 50.06,
  "lon": 19.94,
  "type": "терор",
  "confidence": "неперевірений сигнал",
  "description": "Що саме сказано і чого текст не доводить.",
  "sources": ["https://посилання-на-оригінал"],
  "country": "PL",
  "kind": "X",
  "sourceKind": "X",
  "links": [],
  "avoid": "Лише якщо джерело справді радить щось конкретне."
}
```

### `data/links.json`

Редакційні дуги. Поля: `from`, `to`, `reason`, `relation`, `source`, `speculative`.

- `from` і `to` — `id` із `records.json`.
- `relation`: `географія`, `контекст` або `офіційний режим`.
- `reason` — чому дуга існує і чого вона не доводить.
- `source` — посилання, з якого випливає зв’язок.
- `speculative: true` малює фіолетовий пунктир і слово «припущення».

На записі в панелі зв’язок має форму `{ "id", "reason", "relation", "source", "speculative" }`, де `id` — інший кінець дуги. Це зібрання робить уже сторінка.

### `data/world.geojson` і `data/centroids.json`

Межі всіх країн і території Natural Earth 1:50m (пакунок `world-atlas`) з українськими назвами. Ризик у файл не зашитий: колір береться з `countries.json` під час відкриття сторінки. Щоб перезібрати геометрію після зміни словника назв:

```bash
npm install
node scripts/build-world.mjs шлях/до/countries-50m.json шлях/до/iso.json
```

`countries-50m.json` — це TopoJSON із `world-atlas`, `iso.json` — таблиця ISO 3166-1. Для звичайного оновлення рівнів цей крок не потрібен.

### `data/news.json`

Його пише `scripts/fetch-news.mjs`, не руками. Форма:

```json
{
  "generatedAt": "2026-11-08T05:00:00.000Z",
  "windowDays": 30,
  "note": "звідки взято записи",
  "sources": [{ "name": "Google News: теракт", "ok": true, "received": 12, "error": null }],
  "items": [{
    "id": "n-…",
    "title": "заголовок як у стрічці",
    "link": "https://…",
    "source": "назва видання або домен",
    "published": "2026-11-07T10:00:00.000Z",
    "date": "2026-11-07",
    "lat": 50.0617,
    "lon": 19.9373,
    "place": "Краків",
    "country": "PL",
    "geocodePrecision": "місто",
    "confidence": "одне джерело",
    "origin": "google-news",
    "query": "Краків"
  }]
}
```

`lat`, `lon`, `place`, `country`, `geocodePrecision` можуть бути `null`. Точка ставиться лише якщо в заголовку знайдено місто з `scripts/gazetteer.json` або країну з `data/centroids.json`. Це приблизна прив’язка, не місце події. Записів старші за 30 днів скрипт викидає. Однаковий заголовок в один день лишається один раз; пряме посилання перемагає редірект Google News. Якщо стрічка нічого не повернула, старі ще живі записи не стираються і нові не вигадуються. Після дедуплікації лишається щонайбільше 200 найновіших.

Запуск вручну:

```bash
node scripts/fetch-news.mjs
```

## Щоденні новини і Pages

Два workflow:

- `.github/workflows/news.yml` — щодня о 04:20 UTC і вручну (`workflow_dispatch`). Скрипт оновлює `data/news.json`, комітить його в `main` і одразу публікує сайт. Коміт від `GITHUB_TOKEN` сам по собі інший workflow не запускає, тому публікація стоїть у цій же задачі, після збору новин.
- `.github/workflows/pages.yml` — публікує сайт на кожен push у `main` і вручну, через `actions/deploy-pages`.

Щоб коміт новин проходив, у репозиторії має бути дозволено запис для Actions: Settings → Actions → General → Workflow permissions → Read and write permissions.

Токен workflow не може сам створити сайт Pages: GitHub відповідає `403 Resource not accessible by integration`. Один раз увімкніть джерело вручну:

1. Відкрийте репозиторій на GitHub.
2. Settings → Pages.
3. У блоці Build and deployment поле Source поставте **GitHub Actions** (не Deploy from a branch).
4. Збережіть. Відкрийте Actions → Pages, оберіть останній запуск і натисніть Re-run jobs. Поки джерело не GitHub Actions, крок Configure Pages падає і сайт не з’являється.

Після успішного деплою сайт стоїть на <https://d413422.github.io/danger-map/>.

## Обмеження

- Рівні США зібрані у знімок `meta.asOf`. Це не живий реєстр і не враховує всі обставини українського громадянства.
- Сірий колір — дірка в наборі, а не висновок про безпеку.
- Неофіційні сигнали й новини не перевіряються редакцією сайту. Новина за замовчуванням має мітку «одне джерело».
- Пошук Google News широкий: запит «вибух» або «протест» приносить і побутові сюжети. Сторінка їх не перекваліфіковує в теракт.
- GDELT і Google News іноді не відповідають. Тоді в `sources` буде помилка, а стрічка лишиться попередньою.
- Вулиці на великому масштабі підписані мовою OpenStreetMap. Назви країн поверх глобуса — українською, приблизно до масштабу регіону.
- Тайли OpenFreeMap без ключа, максимальний рівень планети — 14. Цього вистачає, щоб читати квартал і назви вулиць у центрі Кракова.
- Контури Natural Earth спрощені. Спірні території (Північний Кіпр, Сомаліленд, льодовик Сіачен) лишаються окремими полігонами без приписаного рівня.
- Дуга не доводить спільного виконавця, кампанію чи причину.
